# Semih Ertan — Portfolyo

Semih Ertan'ın projelerini, deneyimini ve iletişim bilgilerini sunan kişisel portfolyo sitesi.

## Geliştirme

```bash
npm install
npm run dev
```

## Doğrulama

```bash
npm test
npm run build
```

Site, `main` dalına gönderilen her değişiklikte GitHub Actions ile GitHub Pages'a dağıtılır.
