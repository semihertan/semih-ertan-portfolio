# Semih Ertan — Portfolyo

Semih Ertan'ın projelerini, deneyimini ve iletişim bilgilerini sunan kişisel portfolyo sitesi.

## Geliştirme

```bash
npm install
npm run dev
```

## Doğrulama

```bash
npm test
npm run build
```

Site, Vercel'de GitHub repository'sinden dağıtılır. Build komutu `npm run build`, çıktı dizini `dist` olarak ayarlanır.
